# 04 · 后端开发文档

> 项目：义乌无痕棒球帽源头工厂外贸独立站（SeamCap）
> 技术栈：Go 1.22+ · Chi v5 · SQLite（modernc.org/sqlite）· 标准库优先 · 模块化单体

---

## 1. 分层架构

```
HTTP 请求
   │
   ▼
middleware（请求日志 → 安全头 → 认证/限流 → recovery）
   │
   ▼
handler/          只做：参数绑定、调 service、写响应。禁止写业务逻辑与 SQL
   │
   ▼
service/          业务逻辑：校验、状态流转、权限判断、组合调用
   │
   ▼
repository/       数据访问：全部 SQL、事务。未来迁 PostgreSQL 只改本层
   │
   ▼
SQLite (data/seamcap.db)     storage/（上传文件）  email/（SMTP）
```

约束：
- 统一错误：service 返回 `*apperr.Error{Code, Message, Fields}`，handler 映射为 HTTP 状态码 + JSON。
- context 贯穿全链路；`http.Server` 设置 `ReadHeaderTimeout`、`ReadTimeout`、`WriteTimeout`、`IdleTimeout`。
- 请求体大小限制：公开 API 1MB、上传接口 50MB（图片）/500MB（视频，按配置）。
- 结构化日志 `slog`（JSON 输出到 stdout，可按级别过滤）；**日志禁止出现密码、会话令牌、SMTP 凭据**。

## 3. 数据库设计（DDL 要点）

迁移脚本放 `migrations/0001_init.sql` 起，启动时按序执行未应用的迁移（记录于 `schema_migrations` 表），**初始化不覆盖已有数据**。

### 3.1 表结构

```sql
-- 1. 管理员
CREATE TABLE admin_users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,             -- Argon2id 编码串
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);

-- 2. 会话（数据库 Session）
CREATE TABLE sessions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  token_hash TEXT NOT NULL UNIQUE,         -- 仅存 SHA-256(token)
  admin_id INTEGER NOT NULL REFERENCES admin_users(id) ON DELETE CASCADE,
  ip TEXT, user_agent TEXT,
  expires_at TEXT NOT NULL, created_at TEXT NOT NULL
);

-- 3. 产品
CREATE TABLE products (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  sku TEXT,                                -- 产品编号
  slug TEXT NOT NULL UNIQUE,
  category_id INTEGER REFERENCES product_categories(id) ON DELETE SET NULL,
  short_desc TEXT, detail_desc TEXT,       -- 英文
  material TEXT, cap_shape TEXT, colors TEXT, sizes TEXT, customization TEXT,
  main_image_id INTEGER REFERENCES media_assets(id) ON DELETE SET NULL,
  video_url TEXT,
  is_featured INTEGER NOT NULL DEFAULT 0,  -- 首页精选
  sort_order INTEGER NOT NULL DEFAULT 0,
  status TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','published','archived')),
  seo_title TEXT, seo_desc TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL, published_at TEXT
);
CREATE INDEX idx_products_status_sort ON products(status, sort_order);
CREATE INDEX idx_products_category ON products(category_id);
CREATE INDEX idx_products_featured ON products(is_featured, status);

-- 4. 分类
CREATE TABLE product_categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL, name_en TEXT, slug TEXT NOT NULL UNIQUE,
  description TEXT, image_id INTEGER REFERENCES media_assets(id) ON DELETE SET NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','inactive')),
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);

-- 5. 产品媒体关联
CREATE TABLE product_media (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  product_id INTEGER NOT NULL REFERENCES products(id) ON DELETE CASCADE,
  media_id INTEGER NOT NULL REFERENCES media_assets(id),
  role TEXT NOT NULL DEFAULT 'gallery' CHECK (role IN ('main','gallery','detail')),
  sort_order INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX idx_product_media_product ON product_media(product_id, sort_order);

-- 6. 工艺
CREATE TABLE craftsmanship (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL, slug TEXT NOT NULL UNIQUE,
  summary TEXT, body TEXT,
  cover_image_id INTEGER REFERENCES media_assets(id) ON DELETE SET NULL,
  video_url TEXT,
  sort_order INTEGER NOT NULL DEFAULT 0,
  status TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','published','hidden')),
  seo_title TEXT, seo_desc TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL, published_at TEXT
);

-- 7. 工艺媒体关联（同 5 结构）
CREATE TABLE craftsmanship_media (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  craftsmanship_id INTEGER NOT NULL REFERENCES craftsmanship(id) ON DELETE CASCADE,
  media_id INTEGER NOT NULL REFERENCES media_assets(id),
  sort_order INTEGER NOT NULL DEFAULT 0
);

-- 8. 普通页面
CREATE TABLE pages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  slug TEXT NOT NULL UNIQUE, title TEXT NOT NULL,
  body TEXT,                              -- 受控 HTML（写入前白名单过滤）
  status TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','published')),
  seo_title TEXT, seo_desc TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);

-- 9. 首页内容（单行）
CREATE TABLE home_content (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  hero_title TEXT, hero_subtitle TEXT,
  hero_image_id INTEGER REFERENCES media_assets(id) ON DELETE SET NULL,
  hero_video_url TEXT,
  cta1_text TEXT, cta1_url TEXT, cta2_text TEXT, cta2_url TEXT,
  factory_intro TEXT, contact_blurb TEXT,
  advantages_json TEXT,                   -- [{title,desc,image}]
  process_steps_json TEXT,                -- [{step,desc}]
  footer_text TEXT,
  updated_at TEXT NOT NULL
);

-- 10. 站点设置（KV）
CREATE TABLE site_settings (
  key TEXT PRIMARY KEY,                   -- site_name/whatsapp/email/phone/address/
  value TEXT NOT NULL,                    -- map_link/social_links/seo_title/seo_desc...
  updated_at TEXT NOT NULL
);

-- 11. 询价
CREATE TABLE inquiries (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL, company TEXT,
  email TEXT NOT NULL, whatsapp_phone TEXT,
  product_id INTEGER REFERENCES products(id) ON DELETE SET NULL,
  product_name_snapshot TEXT,             -- 冗余快照：产品删除不丢信息
  product_sku_snapshot TEXT,
  source_page TEXT, estimated_qty TEXT, customization TEXT,
  message TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'new'
    CHECK (status IN ('new','following','replied','completed','spam')),
  internal_note TEXT,
  handled_by INTEGER REFERENCES admin_users(id) ON DELETE SET NULL,
  handled_at TEXT,
  email_notify_status TEXT DEFAULT 'pending' CHECK (email_notify_status IN ('pending','sent','failed','skipped')),
  ip TEXT, user_agent TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);
CREATE INDEX idx_inquiries_status_time ON inquiries(status, created_at);
CREATE INDEX idx_inquiries_email ON inquiries(email);
CREATE INDEX idx_inquiries_created ON inquiries(created_at);

-- 12. 询价事件历史
CREATE TABLE inquiry_events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  inquiry_id INTEGER NOT NULL REFERENCES inquiries(id) ON DELETE CASCADE,
  event_type TEXT NOT NULL,               -- created/status_changed/note/notify
  from_status TEXT, to_status TEXT,
  admin_id INTEGER REFERENCES admin_users(id) ON DELETE SET NULL,
  detail TEXT, created_at TEXT NOT NULL
);

-- 13. 媒体资产
CREATE TABLE media_assets (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  filename TEXT NOT NULL,                 -- 安全化存储文件名（含日期目录）
  original_name TEXT NOT NULL,
  alt_text TEXT DEFAULT '',
  mime_type TEXT NOT NULL, size_bytes INTEGER NOT NULL,
  width INTEGER, height INTEGER,
  sha256 TEXT NOT NULL,                   -- 真实格式校验副产品，兼做去重
  created_at TEXT NOT NULL
);

-- 14. 审计日志
CREATE TABLE audit_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  admin_id INTEGER REFERENCES admin_users(id) ON DELETE SET NULL,
  action TEXT NOT NULL,                   -- login/product.create/product.delete/...
  entity_type TEXT, entity_id TEXT,
  detail TEXT, ip TEXT, created_at TEXT NOT NULL
);
CREATE INDEX idx_audit_time ON audit_logs(created_at);

-- 迁移记录表
CREATE TABLE schema_migrations (
  version TEXT PRIMARY KEY, applied_at TEXT NOT NULL
);
```

### 3.2 SQLite 并发与维护策略

- 连接串：`file:data/seamcap.db?_pragma=journal_mode(WAL)&_pragma=busy_timeout(5000)&_pragma=foreign_keys(1)`。
- `db.SetMaxOpenConns(写并发场景按 CPU 设定)` + WAL 允许"单写多读"；写事务短小。
- 备份使用 SQLite 在线备份 API（`VACUUM INTO` 或 backup 步骤），不停机。
- repository 层不出现 SQLite 方言以外的假设，日期统一存 UTC RFC3339 文本。

## 4. REST API 详细定义

统一前缀 `/api/v1`；请求/响应 JSON；格式见《02-开发文档》5.4。

### 4.1 公开接口

## 5. 关键业务流程

### 5.1 认证与安全

1. 密码：Argon2id（time=1, memory=64MB, threads=4）哈希存储；登录恒定时间比较。
2. 会话：128bit 随机 token，Cookie 只存明文 token（`HttpOnly; Secure; SameSite=Lax; Path=/`），库中存 SHA-256；默认有效期 7 天，勾选“记住登录”后 30 天（`REMEMBER_TTL_HOURS`），均滑动续期。
3. 登录限流：同 IP 5 次/5 分钟、同账号 5 次/5 分钟，超出 429。
4. 图形验证码：登录必须携带 `captcha_id + captcha_code`；4 位数字 PNG（132×44，噪点/干扰线/波浪扭曲），5 分钟有效、一次性使用，签发与校验均按 IP 限流（60 张 / 30 次每 5 分钟）；校验失败无论对错都会消耗该挑战。
5. CSRF：管理后台写操作要求 `X-CSRF-Token`（登录时下发，绑定会话）；公开询价接口用 Origin/Referer 校验 + 一次性提交 token。
6. CORS：默认同源（不返回 CORS 头）；如需开放再按域名白名单配置。
7. 安全头中间件：`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`（后台）、`Referrer-Policy: strict-origin-when-cross-origin`、基础 CSP。

### 5.2 询价处理（POST /inquiries）

```
① Content-Length 校验（≤1MB）
② 字段校验：name≤100、email(格式+≤200)、message(10–5000)、其余≤500
③ product_id 存在性 + 已发布检查（否则置空，不报错）
④ honeypot 非空 → 伪装成功返回（静默丢弃）；提交间隔 <3s 同 IP → 429
⑤ IP 限流：10 次/小时/IP
⑥ 落库（事务：inquiries + inquiry_events[created]）
⑦ 邮件通知异步投递（goroutine + 超时控制）：
     成功 → email_notify_status=sent
     失败 → =failed + 错误日志（询价数据不受影响）
⑧ 返回 201
```

### 5.3 邮件模块（email/）

- 配置全部来自环境变量：`SMTP_HOST/SMTP_PORT/SMTP_USER/SMTP_PASS/SMTP_FROM_NAME/NOTIFY_EMAIL/SMTP_TLS(starttls|ssl|none)`。
- 提供 `SendTestMail()` 配置自检接口（管理后台按钮触发）。
- 模板：新询价通知（收件人工厂邮箱），含客户信息与产品快照；正文纯文本 + 简单 HTML 双部分。
- **部署前必须完成真实收发测试**；凭据仅存环境变量，不进 Git。

### 5.4 文件存储模块（storage/）

- 白名单 MIME：`image/jpeg, image/png, image/webp, image/avif, video/mp4`。
- 真实格式校验：读文件头 magic number（JPEG FFD8 / PNG 89504E47 / WebP RIFF / MP4 ftyp），不信任扩展名。
- 大小限制：图片 10MB、视频 500MB（可配置）。
- 文件名：`uploads/{yyyy}/{mm}/{ulid}.{ext}`，原始名仅存 `original_name`；拒绝 `..`、绝对路径、覆盖检查。
- 上传失败自动清理半成品文件；删除前查 `products/craftsmanship/pages/home_content` 引用计数。
- 接口抽象：`Storage interface { Save/Replace/Delete/URL }`——第一期 LocalStorage 实现，预留 S3/OSS 适配。

### 5.5 SEO 模块（seo/ + SSR）

- Go 模板渲染所有前台页面完整 HTML；每页注入独立 title/description/canonical/OG。
- `GET /sitemap.xml`：动态生成，仅含 published 产品/工艺/页面 + 固定页；草稿/下架不入。
- `GET /robots.txt`：允许抓取前台，`Disallow: /admin/`。
- 产品图片 URL 带 `alt` 由模板输出。

## 7. 部署（deploy/）

### 7.1 systemd（deploy/seamcap.service）

```ini
[Unit]
Description=SeamCap B2B Website
After=network-online.target

[Service]
Type=simple
User=seamcap
WorkingDirectory=/opt/seamcap
EnvironmentFile=/opt/seamcap/.env
ExecStart=/opt/seamcap/bin/seamcap
Restart=always
RestartSec=5
NoNewPrivileges=true
ProtectSystem=strict
ReadWritePaths=/opt/seamcap/data /opt/seamcap/uploads

[Install]
WantedBy=multi-user.target
```

### 7.2 Caddy（deploy/Caddyfile）

```
example.com, www.example.com {
  encode gzip zstd

  # handle_path 剥掉前缀后按各自 root 服务：/static/x -> web/static/x，/uploads/x -> uploads/x
  handle_path /static/* {
    root * /opt/seamcap/web/static
    file_server
    header Cache-Control "public, max-age=31536000, immutable"
  }

  handle_path /uploads/* {
    root * /opt/seamcap/uploads
    file_server
    header Cache-Control "public, max-age=31536000, immutable"
  }

  handle {
    reverse_proxy 127.0.0.1:8080
  }
}
```

（Nginx 等价配置见 deploy/nginx.conf。）www → 根域名 301 统一。

### 7.3 备份（deploy/backup.sh）

```bash
#!/usr/bin/env bash
set -euo pipefail
TS=$(date +%Y%m%d-%H%M%S)
sqlite3 /opt/seamcap/data/seamcap.db "VACUUM INTO '/opt/seamcap/data/backups/db-$TS.db'"
tar -czf /opt/seamcap/data/backups/uploads-$TS.tar.gz -C /opt/seamcap uploads
# 保留最近 30 份；建议再同步到异地/对象存储
```

cron 建议：每日 03:00；**每季度执行一次恢复演练**。部署/升级严禁覆盖 `data/` 与 `uploads/`。
