## 一、ui-ux-pro-max Skill 安装

### 1.1 Skill 简介

[ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 是一个面向 AI 编程助手的 UI/UX 设计智能技能，内置基于 BM25 搜索的本地设计系统推理引擎（纯 Python 标准库，无网络调用），核心能力：

- 79 种可搜索 UI 风格（50 种激活）
- 192 个行业配色方案 + 192 条行业推理规则
- 74 组字体搭配、25 种图表类型、119 条 UX 准则
- 22 种技术栈实现建议（含 html-tailwind 等原生 Web 方案）
- MIT 开源协议

### 1.2 前提条件

- Python 3.x（仅标准库，无需第三方包）。Windows 下使用 `python` 命令。

```bash
python --version
```

### 1.3 安装步骤（本项目实际执行的命令）

在项目根目录 `D:\SeamCap` 下执行：

```bash
# 1. 预览（可选）
npx -y ui-ux-pro-max-cli init --ai codebuddy

# 2. 正式安装（目标平台：CodeBuddy，安装到 .codebuddy/skills/）
npx -y ui-ux-pro-max-cli init --ai codebuddy
```

安装器输出：

```
UI/UX Pro Max Installer
info Installing for: CodeBuddy (.codebuddy/skills/)
- Installing files...
√ Generated from templates!
success UI/UX Pro Max installed successfully!
```

### 1.5 项目设计系统生成

利用技能的搜索引擎，针对本项目"B2B 制造业工厂外贸站"生成了设计系统基线，并已持久化：

```bash
python .codebuddy/skills/ui-ux-pro-max/scripts/search.py \
  "B2B manufacturing factory export wholesale cap hat" \
  --design-system --persist -p "SeamCap"
```

生成文件：`design-system/seamcap/MASTER.md`（全局设计规范唯一事实来源）。

核心结论（与需求文档"米白、深海军蓝、炭黑"配色要求吻合）：

| 项目 | 结果 |
|------|------|
| 页面模式 | Trust & Authority + Conversion（信任权威 + 转化） |
| 主色 Primary | `#0F172A`（深海军蓝） |
| CTA 强调色 | `#0369A1`（克制蓝，用于询价/联系入口） |
| 背景 Background | `#F8FAFC`（米白） |
| 字体 | Plus Jakarta Sans（Google Fonts） |
| 禁忌 | 玩乐风设计、AI 紫粉渐变、emoji 当图标 |

### 1.6 日常使用方式

```bash
# 生成/刷新设计系统建议
python .codebuddy/skills/ui-ux-pro-max/scripts/search.py "wholesale product listing" --design-system

# 单领域查询（风格 / 配色 / 字体 / UX 准则 / 图表）
python .codebuddy/skills/ui-ux-pro-max/scripts/search.py "glassmorphism" --domain style
python .codebuddy/skills/ui-ux-pro-max/scripts/search.py "form validation error" --domain ux

# 技术栈最佳实践（本项目用 html-tailwind 条目作原生 Web 参考）
python .codebuddy/skills/ui-ux-pro-max/scripts/search.py "image gallery lazy load" --stack html-tailwind
```

自然语言触发：在 AI 助手中直接说"为产品列表页设计卡片布局"等，即可命中该技能。

### 1.7 更新与卸载

```bash
npx -y ui-ux-pro-max-cli update      # 更新到最新版
npx -y ui-ux-pro-max-cli uninstall   # 从当前项目卸载
```

## 二、开发环境安装

### 2.1 环境清单

| 工具 | 版本要求 | 用途 | 检查命令 |
|------|---------|------|---------|
| Go | ≥ 1.22 | 后端服务 | `go version` |
| Git | 任意近期版本 | 版本管理 | `git --version` |
| Node.js | ≥ 20（可选） | skill 安装、前端开发辅助 | `node --version` |
| Python | ≥ 3.10 | skill 搜索引擎 | `python --version` |
| SQLite | 无需单独安装 | 数据库（驱动内置） | — |

### 2.2 Go 安装

**Windows：**
1. 从 https://go.dev/dl/ 下载 `go1.22.x.windows-amd64.msi` 安装。
2. 验证：`go version`。
3. 配置模块代理（国内网络）：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

**Linux（Ubuntu/Debian，生产服务器）：**

```bash
wget https://go.dev/dl/go1.22.10.linux-amd64.tar.gz
sudo rm -rf /usr/local/go && sudo tar -C /usr/local -xzf go1.22.10.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.profile && source ~/.profile
```

### 2.3 其他工具

- **Git**：https://git-scm.com/downloads
- **Node.js**：https://nodejs.org/（仅 skill 安装与前端辅助需要）
- **编辑器**：VS Code + Go 官方插件，或 GoLand。

## 三、项目初始化（首次开发时执行）

### 3.1 初始化 Go 模块

```bash
cd D:\SeamCap
go mod init github.com/<你的账号>/seamcap

# 核心依赖（按需在开发中引入）
go get github.com/go-chi/chi/v5          # 轻量路由
go get modernc.org/sqlite                # 纯 Go SQLite 驱动（无 CGO，Windows 友好）
go get golang.org/x/crypto/argon2        # 密码哈希（或 bcrypt）
go get github.com/joho/godotenv          # .env 加载
```

> SQLite 驱动选型说明：`modernc.org/sqlite` 为纯 Go 实现，Windows/交叉编译零障碍，作为本项目首选；如后续迁移 PostgreSQL，仅需替换 repository 层驱动与方言 SQL。

### 3.2 创建目录骨架

```bash
mkdir -p cmd/server internal/{handler,service,repository,middleware,model,config,storage,email,logger} \
         migrations web/static/{css,js,img,fonts} web/templates/{public,admin} \
         data uploads docs
```

完整目录规划见《02-开发文档》第 3 节。

### 3.3 环境变量配置

复制 `docs/.env.example`（随本套文档交付）为项目根目录 `.env`，按需修改。**`.env` 必须加入 `.gitignore`，严禁提交真实凭据。**

```gitignore
# .gitignore 必含条目
.env
data/
uploads/
*.db
*.db-wal
*.db-shm
```

## 四、本地运行

```bash
# 启动开发服务（默认监听 :8080）
go run ./cmd/server

# 运行全部测试
go test ./...

# 构建生产二进制（Windows）
go build -o bin/seamcap.exe ./cmd/server

# 构建生产二进制（Linux，交叉编译）
set GOOS=linux & set GOARCH=amd64
go build -o bin/seamcap ./cmd/server
```

启动后访问：

| 地址 | 说明 |
|------|------|
| http://localhost:8080/ | 前台首页 |
| http://localhost:8080/admin/ | 管理后台 |
| http://localhost:8080/api/v1/health | 健康检查 |
| http://localhost:8080/api/v1/site | 公开站点信息 API |

## 五、常见问题

| 问题 | 处理方式 |
|------|---------|
| `go get` 超时 | 确认已设置 GOPROXY（见 2.2），或检查代理/防火墙 |
| skill 搜索无输出 | 确认在项目根目录执行，Python 为 3.x；Windows 用 `python` 而非 `python3` |
| SQLite 数据库被锁 | 确认连接串启用 WAL 与 busy_timeout（后端已内置），避免多进程同时写 |
| 8080 端口占用 | 修改 `.env` 中 `PORT` 后重启 |
| Google Fonts 加载慢 | 生产环境建议自托管字体文件（见《03-前端开发文档》7.2） |
