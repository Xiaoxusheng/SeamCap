# 管理后台 UI 精细化重设计 V2 · Mintlight Enterprise Dashboard

日期：2026-10-24
状态：实施中
基线：`docs/plans/2026-10-24-admin-mintlight-redesign.md` 的薄荷绿方向保持不变，本次只做像素级结构与密度改造。

## 目标

解决当前后台"主题对了但界面不精致"的问题：页面标题重复、KPI 卡过高且留白过多、仪表盘信息重复、图标与字号层级偏弱、表格密度不合理。所有 14 个后台页面统一到同一套 214px 侧栏 / 58px 顶栏 / 10–11px 卡片圆角 / 12–13px 正文的尺寸体系。

## 做什么

1. `theme.ts` + `styles/admin.css`：替换为 V2 指定 Token（主色 `#1B9A78`、画布 `#F4F8F6`、侧栏 `#EAF7F2`、选中 `#D5F0E5`），统一控件高度、表格行高、圆角、字号与动效变量。
2. `AdminLayout`：侧栏 214/68px、Logo 区 64px、菜单项 38px；折叠按钮移入顶栏，左侧显示真实面包屑；顶栏仅保留真实全局搜索、真实新询价提醒与账户菜单，移除无落地的帮助入口。
3. `PageHeader`：删除 kicker 与装饰圆点，标题只出现一次；标题区 62–70px；所有页面移除重复模块名。
4. `dashboard/index.tsx`：KPI 四列 136px；第二行改为「内容资产概览 58% + 待处理事项 42%」；第三行改为「最近询价 59% + 最近更新产品 41%」；删除重复的产品状态环形图；所有数字与跳转均来自现有 `/admin/dashboard` API。
5. 其余页面：产品/分类/媒体/工艺/页面/首页/询价/设置/审计/登录逐页调整标题区、工具栏、网格、表格、表单、空/错/加载态与图标尺寸。
6. 构建产物同步到 `web/admin/`，8091 独立实例逐页实机验收，并跑 Go 回归。

## 不做什么

- 不改 Go 业务、API Contract、数据库、认证、CSRF、上传与删除逻辑。
- 不新增依赖、不引入图表库、不造暗色模式。
- 不虚构询价、产品、趋势、百分比或通知数量。
- 不改公开站页面与 `web/static`。

## 验证

1. `cd web/admin-src && npm run build` 零错误。
2. 8091 实例（独立数据库副本）验证码登录后，1704×825 / 1440 / 1024 / 375 截图逐页检查：无溢出、KPI 136px、图标底板 34px、行高符合、空数据不产生空白占位。
3. 交互抽查：搜索、刷新、KPI 与待办跳转、询价行跳转、产品行跳转、侧栏折叠与 Tooltip。
4. `go test ./...` 回归并如实记录环境限制。
