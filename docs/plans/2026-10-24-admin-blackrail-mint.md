# 管理后台 UI 重构 · Blackrail Mint

日期：2026-10-24
状态：实施中
方向：**Light SaaS Dashboard + Soft Mint UI + Clean Enterprise Admin**
一句话：纯黑导航轨道（Blackrail）托住柔和薄荷色的内容工作区，克制、明亮、信息密度高，支持完整暗色模式。

---

## 一、可直接复用的设计提示词

> 请重做 SeamCap 管理后台，保持 React 18 + TypeScript + Vite + Ant Design 6 技术栈，不引入新依赖、不改 API 与业务逻辑。
>
> **气质**：Light SaaS Dashboard 的清晰信息层级 + Soft Mint UI 的柔和薄荷强调色 + Clean Enterprise Admin 的克制与专业。不要玻璃拟态大面积渐变、不要霓虹光晕、不要大圆角卡通感。
>
> **布局**：左侧 236px 纯黑 `#000000` 导航（折叠 72px），品牌区 64px 高，薄荷色方形 Logo；导航项 40px 高、10px 圆角、16px 图标、13px 文字；分组标题 10px 大写灰字 `#5F6A65`，组间距 10px；选中项底色 `#D9F8EA`、文字 `#04120C`、图标 `#0B7D5B`，不使用左侧竖条；悬停 `rgba(255,255,255,.06)`。右侧为 64px 半透明玻璃顶栏（`rgba(255,255,255,.86)` + `backdrop-filter: blur(16px)`），底边 1px `#E4E9E6`，含面包屑、真实全局搜索、新询价提醒、明暗主题切换与账号菜单。主内容顶部先显示 30px 高的胶囊快捷导航（10 个页面快跳、当前页薄荷浅底），再显示 26px 页面标题。主画布 `#F4F6F5`，内容最大宽度 1520px，左右留白 28px，顶部 24px。移动端 ≤1024px 侧栏收为黑色 Drawer。
>
> **色彩**：品牌薄荷 `#12A37D`，深色悬停 `#0E8F6D`，浅底 `#E3F8EF`；正文 `#101614`，次级 `#586661`，弱化 `#86958F`；边界 `#E4E9E6`，分隔线 `#EDF2EF`。数据色只用于状态：绿 `#12A37D`、蓝 `#4E8BEE`、琥珀 `#E6A13B`、珊瑚 `#F16F73`、紫 `#8A7AE6`、灰 `#84918F`，一律「浅底 + 深字 + 10px 圆角胶囊」，不铺满整块卡片。
>
> **卡片**：白色表面、1px 边界、14px 圆角、阴影 `0 1px 2px rgba(16,24,20,.04), 0 8px 24px -14px rgba(16,24,20,.10)`；内边距 20px；标题栏 52px 高、14px/600 标题、右侧 12.5px 薄荷色文字链接；卡片之间 16px 间距。悬停仅上浮 2px 并加深阴影，不做缩放；表格行不做上浮。
>
> **字体**：Inter / PingFang SC；正文 13px/1.55；页面标题 26px/600、字距 -0.02em；区块标题 15px/600；辅助文字 12px；数字统一 `font-variant-numeric: tabular-nums`。页面标题只出现一次，标题区 72px 高，描述 12.5px。
>
> **动效**：页面进入 260ms 淡入 + 上移 8px（`cubic-bezier(.16,1,.3,1)`）；指标卡按 45ms 阶梯浮现；卡片悬停 180ms；按钮按下缩放 0.98；导航选中 180ms 底色过渡；表格行悬停 120ms；图片悬停 220ms 放大 1.03；弹窗/抽屉沿用 AntD 动效并加 2px 上浮；主题切换 220ms 色彩过渡。全部在 `prefers-reduced-motion` 下降级。
>
> **暗色**：画布 `#0B0E0D`，卡片 `#141817`，浮层 `#191E1C`，边界 `#262D2A`，正文 `#ECF3F0`，次级 `#A7B5AF`，品牌薄荷提亮为 `#3DDCAB`；侧栏仍是纯黑，仅用 `#151917` 分隔；状态色改为 12% 透明底 + 高亮文字；阴影改为纯黑低透明度；登录页与预览区同步暗色。切换入口放在顶栏，支持「浅色 / 深色 / 跟随系统」，持久化到 localStorage，首屏脚本防闪烁。

## 四、动效规范

| 场景 | 效果 | 时长 / 缓动 |
| --- | --- | --- |
| 路由进入 | 透明度 0→1，Y +8→0 | 260ms `cubic-bezier(.16,1,.3,1)` |
| KPI 阶梯 | 每卡延迟 45ms 上浮 | 260ms |
| 卡片悬停 | `translateY(-2px)` + 阴影加深 | 180ms `cubic-bezier(.2,0,0,1)` |
| 按钮按下 | `scale(.98)` | 120ms |
| 导航项 | 底色/文字色过渡 | 180ms |
| 表格行悬停 | 底色过渡 | 120ms |
| 图片悬停 | `scale(1.03)` | 220ms |
| 搜索面板 | Y -4px + scale .99→1 | 160ms |
| 主题切换 | 画布/卡片/边界颜色过渡 | 220ms |
| 骨架屏 | 1.35s 循环微光 | 1.35s |
| 降低动效 | 全部动画 0.01ms，保留状态变化 | `prefers-reduced-motion` |

交互规则：

1. 导航选中态使用薄荷实底，折叠后仅保留 40px 图标位并显示右侧 Tooltip。
2. 顶栏搜索 `Ctrl / ⌘ + K` 聚焦，防抖 280ms，结果覆盖产品与询价，回车跳产品搜索。
3. 明暗切换为三项菜单「浅色 / 深色 / 跟随系统」，当前项打勾；切换立即写入 `data-theme`。
4. 卡片整体可点时使用 `role="link"` + Enter/Space 支持，并保持焦点环。
5. 表格、卡片、抽屉内的危险操作保留二次确认与原有业务语义。
6. 移动端 ≤1024px 侧栏改为 Drawer，选择菜单后自动关闭；≤980px 询价改为列表/详情切换。

## 六、不做什么

- 不改 Go 后端、API 契约、认证、CSRF、上传与删除逻辑。
- 不新增 UI / 图表 / 动画库，不虚构数据。
- 不改公开站页面与 `web/static`。
- 不删除任何现有业务操作。
