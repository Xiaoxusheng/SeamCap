# 管理后台 UI 全面重设计 · Mintlight Enterprise Console

日期：2026-10-24
状态：已完成并通过实机验收
最终方向：**浅薄荷绿侧栏 + 白色顶栏 + 浅灰绿工作区**（用户 2026-10-24 决策）

> 说明：任务书最初提出的「钴蓝 + 顶部主导航」方案未采用。工作区在实施期间并行推进了两套方向，最终经用户确认保留 Mintlight 绿色侧栏方案。后续后台页面以 `design-system/seamcap/MASTER.md` 为准。

## 目标

在 React 18 + TypeScript strict + Vite + Ant Design 6 技术栈内，把管理后台重做成一套有独立品牌识别的轻量内容工作台：

- 统一的 Mintlight 设计 Token、AntD 主题与全局样式。
- 浅薄荷绿侧栏 + 58px 白色顶栏（真实全局搜索、询价通知、帮助、账户菜单）。
- 10 个内容页面 + 3 个编辑页 + 登录页全部纳入新设计体系。
- 保留全部 API 契约、认证、CSRF、表单校验、删除确认、媒体引用冲突与保存语义。
- 构建产物同步到 `web/admin/`。

## 最终实现

### 框架与导航

- `AdminLayout`：228px 浅薄荷绿侧栏（可收起为 68px，状态持久化），分组导航，当前项 `#D6F1E7` 浅底 + 深绿文字。
- 顶栏：全局搜索（产品/SKU/询价，Ctrl+K，真实 API）、新询价 Badge（真实 dashboard 数据）、帮助 Popover、管理员下拉菜单。
- ≤1024px：侧栏折叠为左侧 Drawer，顶栏提供菜单与搜索按钮；选择页面后自动关闭。
- 登录页：薄荷绿品牌视觉区 + 真实帽饰摄影 + 白色表单卡；移动端隐藏视觉区、显示品牌行。

### 设计体系

- 品牌薄荷绿 `#199B78`，画布 `#F5F9F8`，导航 `#EDF8F4`，石墨正文 `#202A2B`。
- 语义色：蓝（跟进）、绿（发布/成功）、琥珀（草稿/待处理）、珊瑚（新询价/提醒）、灰（归档/停用）、红（失败/危险）、紫（少量辅助数据）。
- 状态标签文字 + 颜色双通道；表格表头 45px、行高约 56–60px；面板 12px 圆角 + 1px 边界 + 极轻阴影。
- 动效 120/180/220ms，`prefers-reduced-motion` 降级；触屏媒体操作常显。

### 页面

1. 仪表盘：真实指标卡 + 产品状态环形图 + 目录构成条 + 最近询价表 + 最近产品 + 待处理事项。
2. 产品管理：图片目录 / 紧凑表格双视图、筛选、分页、精选、复制、删除。
3. 产品编辑：分区内容编辑 sheet + 发布侧栏 + 图库。
4. 分类管理：真实汇总条 + 目录表格 + CRUD + 删除迁移/停用。
5. 媒体库：紧凑上传条 + 响应式网格 + 大图/侧栏预览 + ALT/替换/URL/删除。
6. 工艺管理：作品集卡片。
7. 工艺编辑：内容编辑 sheet + 发布侧栏 + 图库。
8. 页面管理：分隔式 CMS 列表。
9. 页面编辑：HTML 编辑器 + 沙箱预览。
10. 首页内容：分区导航 + 分区表单 + 实时首屏预览（≤1320 收起）。
11. 询价管理：桌面双栏 Inbox + 事件时间线；≤980 列表/详情切换；`?inquiry=ID` 直达详情。
12. 站点设置：分组设置页 + 社交链接行编辑器。
13. 审计日志：只读信息密集表格。
14. 登录页：品牌视觉 + 表单；验证码、记住登录、错误提示、Loading。

## 不做什么

- 不改 Go 后端业务、API 契约、数据库结构、公开站样式。
- 不新增业务路由、不引入新 UI/图表/动画依赖。
- 不虚构指标、趋势、上传进度或产品图片。
- 不做暗色模式（当前无需求）。
