# Day Mode（白天模式）

> 本文件补充 `MASTER.md`：站点在 2026-10-25 增加浅色主题，**布局与区块不变**，只换材质与色值。
> 开关：导航右侧圆形按钮（太阳/月亮），记忆在 `localStorage.shirun_theme`；未手动选择时跟随系统。

---

## 令牌对照（`html[data-theme="light"]`）

| 令牌 | 深色（默认） | 浅色（Day Mode） | 说明 |
|---|---|---|---|
| `--bg` | `#0C0A09` | `#F6F2E9` | 暖纸白，不是纯白 |
| `--bg-soft` | `#13100E` | `#EFE8DA` | 输入/弹层底色 |
| `--ivory` | `#F5F1EA` | `#191512` | 语义是「强调文字」，浅色下翻转成墨色 |
| `--text` | `#EDE7DC` | `#2C2721` | 正文 |
| `--muted` | `#A8A29E` | `#5C554B` | 次要文字（6.5:1） |
| `--faint` | `#6F6A64` | `#6E6659` | 小号 meta（5.1:1） |
| `--gold` | `#C9A24B` | `#8A6116` | 强调/眉标 |
| `--gold-bright` | `#E8CE9E` | `#7A5510` | 链接、CTA 文字 |
| 大字号 `em` | `--gold-bright` | `#96691A` | 仅 h1/h2/h3 em，大字 3:1 即可 |
| `--glass-bg` | 白 10%→3% | 白 90%→66% | 浅底上靠白度与阴影立住 |
| `--glass-line` | 白 14% | 墨 14% | 边界 |
| `--shadow-md/lg` | 黑投影 | 暖褐投影 | 避免灰脏 |

## 例外规则（重要）

- **压在图片上的深色胶囊**（`.glass-chip`、`.vcard__play`、`.pack-item__play`、`.lightbox__close/nav`）在浅色主题下必须保留浅色文字 —— 它们不受 `--ivory` 翻转影响。
- 浅色下卡片分离度靠 **白度 + 暖褐阴影 + 墨色描边**，不要用灰色底（会显脏）。
- 浅色玻璃透明度不要低于 0.66，否则正文可读性下降。
- `color-scheme` 必须随主题切换，原生 select/滚动条才不会错色。

## 玻璃导航（两套主题共用）

- 结构：`fixed` 外层透明 + `.nav__inner` 玻璃胶囊（高 66，滚动后 58）；左右仍对齐 `.wrap(1240)`。
- 材质：`backdrop-filter: blur(22px) saturate(160%)` + 1px 边 + 上沿内高光。
- 深色滚动态底色 `rgba(20,17,14,.86)`；浅色 `rgba(253,250,244,.95)`。
- 移动端（≤560）三个控件压到 38/38/40，避免胶囊挤压品牌。
- 锚点跳转统一 `scroll-margin-top: 96px`，防止落点被胶囊盖住。

## 局部动态（Liquid Glass 的「动」）

| 位置 | 效果 | 降级 |
|---|---|---|
| 导航 | 滚动收紧 + 底色加深 | 无 |
| 产品卡 / 卖点卡 / 会员区 / 表单 / 打包图 | 指针跟随的镜头高光（`--lx/--ly` + `radial-gradient`） | 触屏与 `prefers-reduced-motion` 下不绑定 |
| `.glass-frame` | 斜向扫光 | 同上 |
| 按钮 | hover 上移 2px（不改尺寸） | 同上 |
| 全站 | `.reveal` 滚动显现 + 级联 | `reduce` 下直接可见 |
